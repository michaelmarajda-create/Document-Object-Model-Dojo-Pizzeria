Purpose: A JavaScript script that models a pizza kitchen to create custom or entirely random pizza objects.

Core Factory (pizzaOven): The main blueprint function that takes ingredients as arguments and packages them into a structured object.

Smart Randomization: Uses Math.random() to pick a single crust and sauce from predefined option arrays.

Duplicate Prevention: A helper function gathers multiple random cheeses and toppings while dynamically checking for duplicates to ensure unique combinations.

Automation Engine (randomPizza): Acts as a "Chef's Choice" command, pulling random ingredients from the menus and instantly running them through the oven function.

Dynamic Output: Prints the resulting pizza objects directly to the console, generating a unique menu combination every single time the script runs.
